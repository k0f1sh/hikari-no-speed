# Hikari no Speed — 光速で旅する太陽系

太陽系の「ほとんど何もない空間」を移動する Three.js アプリ。天体の大きさと距離に、必ず同じ変換係数を使います。太陽と8惑星、月を表示します。星空やテクスチャは加えず、空間の静けさを優先しています。

## 起動

Node.js 20.19+ または 22.12+ が必要です。

```sh
npm install
npm run dev
```

表示されたローカル URL（通常 http://localhost:5173/）を開きます。

```sh
npm run build
npm run preview
```

ビルドした `dist/` を静的ホスティングへ配置できます。Vite の `base: './'` により GitHub Pages のサブディレクトリにも対応します。外部フォント、外部画像、API、React は使いません。

## 最初の遊び方

1. 「光速の旅を始める」を押し、太陽の大きさを見ます。
2. 右側の地球の「向く」を押します。点線のマーカーが方向を示します。球体のサイズは拡大していません。
3. 地球の「進む」で旅を開始。向きやキー操作を気にせず実際の距離を進めます。
4. 右側の速度選択で速度を変更します。「光速にする」なら 299,792.458 km/s。太陽から地球まで光でも約8分20秒。速く確認する場合は、明示的に「超光速」を選択できます。
5. 到着後、右側の Sun を選択して太陽を見てください。地球からは約0.53度にしか見えません。

自動移動は途中の天体をすり抜け、目的地の観察位置で止まります。直線距離に沿って移動する体験用の仕様です。Esc、手動移動キー、自由飛行の開始、別の目的地の選択でも停止します。画面が非表示になった場合も停止します。ジャンプは各天体の右端の ↗ で、スキップした移動距離を表示します。通常の目的地選択は向きを変えるだけです。

## 自由飛行とキー操作

宇宙画面をクリックするとマウスがロックされます。Esc で解除して UI を操作できます。開始時はマウスをロックしないため、そのまま画面上のボタンを操作できます。

| 操作 | 動作 |
| --- | --- |
| Mouse | 視点回転（自由飛行中） |
| W / S | 前進 / 後退 |
| A / D | 左右移動 |
| Space / Shift | 上 / 下移動 |
| Wheel 上 / 下 | 速度を上げる / 下げる |
| M | マーカーの ON / OFF |
| O | 薄い軌道線の ON / OFF |
| G | 速度に合わせたグリッドの ON / OFF |
| Esc | マウスを解除、自動移動を停止 |

速度は 1、10、100、1,000、10,000 km/s と、1c、10c、100c、1,000c。1c は正確な光速299,792.458 km/sです。光速より速い値は移動確認のための体験用です。

マーカーは画面上の補助表示であり、実寸の天体ではありません。画面外の目的地には方向の目印が出ます。「向く」で正確に向けます。M、O、G を OFF にすれば、ほぼ黒い空間と実寸の天体だけになります。

## 月

右側の Earth の下に Moon（月）があります。選択すると月を向き、自動移動・ジャンプ・マーカーにも対応します。

月の平均直径は **3,474.8 km**、地球中心から月中心までの距離は **384,400 km**。NASA の平均半径1,737.4 kmと軌道長半径384,400 kmを使用しています。[NASA Moon Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)

公転は行わず、地球から +Z 方向に固定配置します。月の細い軌道線は地球中心の円です。月の太陽距離はこの固定配置から計算した値で、現在の天文位置を示すものではありません。地球からの距離は地球の直径約30個分、月の見かけの直径は約0.52度です。

## 移動グリッド

初期状態で ON。G キーまたは右側のボタンで切り替えます。HUD に「1マス = … km」を表示します。グリッドは移動のための目盛りで、宇宙に存在する物体ではありません。

間隔は「現在速度 × 3秒」を最も近い10の累乗へ丸めます。光速では1マス100万km、約3.34秒で横切ります。速度を変えると古い間隔と新しい間隔をフェードで切り替えます。5マスごとの線は少し明るく、遠くの線は消えます。

横方向の線は太陽系の座標に固定されており、移動すると後ろへ流れます。目盛りの平面はカメラの高度に追従して下側に表示するため、垂直方向の距離を測るものではありません。カメラ近くの範囲だけを生成し、原点からの位相を倍精度で計算してから GPU へ渡します。天体の縮尺や移動速度は変えません。

## スケール計算とデータ

`src/data/celestialBodies.ts` に平均直径と代表的な軌道長半径を km 単位で集約しています。全天体の出典URLをデータ内に記録しています。2026年10月8日にNASA NSSDCAの各Fact Sheetを確認し、平均直径は体積平均半径の2倍、惑星の距離は「Orbital parameters」の軌道長半径をkmに換算した値に統一しました。出典の桁数を維持し、追加の丸めは行っていません。同じページのJ2000軌道要素とは区別しています。公転や現在の天体配置は再現せず、惑星は太陽から同じ方向に並ぶ固定配置です。月は地球を基準とした相対配置です。軌道線は平均距離を半径とした円で、離心率・軌道傾斜は扱いません。

`src/utils/units.ts` の定数だけで縮尺を変更できます。

```ts
KM_PER_WORLD_UNIT = 100000
worldPosition = distanceFromSun / KM_PER_WORLD_UNIT
sphereRadius = diameter / 2 / KM_PER_WORLD_UNIT
```

地球の半径は 0.06371 world unit、太陽からの距離は 1,495.98 world units。天体のサイズの最低値や距離の短縮は設けていません。

HUD の太陽距離は中心まで、中央の目的地表示と最寄り天体の距離は表面までです。最寄り天体の所要時間は表面へ直進する場合の参考値です。右側の目的地は観察位置までの残距離と到着予想を表示します。自動移動・ジャンプは観察しやすいよう中心から半径の5倍で止まり、右側には「観察位置に到着」と表示します。手動移動には線分と球の交差判定を使い、半径の1.05倍の安全境界で停止します。

移動距離はフレーム間の実経過時間から計算し、低FPSでも実時間に対する速度を維持します。画面の非表示やフォーカス喪失で自動移動と手動入力を停止し、復帰時は時計をリセットします。休止中の時間は移動に加算しません。

惑星は単色の球体です。照明は遠方の惑星を過度に暗くしないため、太陽方向からの平行光と微弱な環境光で近似しています。土星の環や物理的な光量減衰は未実装です。

## Three.js の精度への対処

論理カメラ位置は JavaScript の倍精度で保持し、毎フレーム、天体の論理位置からカメラ位置を差し引きます。描画カメラは常に原点です。近くの天体は GPU へ送る前に小さい相対座標になり、遠くへ旅しても局所的な精度を保ちます。

軌道線も各頂点で倍精度の原点減算を行った後に Float32 バッファへ書き込みます。巨大な orbit mesh を単純に平行移動する方式を避けています。描画時の再配置だけなのでユーザーの論理位置は連続します。

広い near/far 範囲には Three.js の `logarithmicDepthBuffer` を使います。[Three.js 公式 WebGLRenderer ドキュメント](https://threejs.org/docs/pages/WebGLRenderer.html)参照。深度バッファと座標精度は別の問題なので、カメラ相対座標と併用しています。実寸で画面上の1ピクセル未満になる惑星が見えないのは意図した挙動です。

## 検証

```sh
npm run build
npm run check
```

チェックは共通縮尺、角直径、正確な光速と速度段階、60/10/5 FPSでの手動・自動移動、休止復帰、入力解除、観察位置での距離とETA、超光速の手動衝突判定、自動移動の天体通過、全90通りの天体間移動と移動距離の計算を検証します。

Playwrightで実ブラウザ上の速度変更、地球・月への自動移動、観察位置での到着表示を確認しています。blur/focusおよびvisibilitychangeイベントを発生させ、停止と復帰後の位置保持も検証しています。マウスロックの操作と、実際のタブ切り替えによる長時間休止は手動確認の対象です。

## GitHub Pagesで公開

リポジトリの Settings → Pages → Build and deployment の Source を GitHub Actions に設定します。`main`へのpushで整形・型・動作のチェックとビルドを行い、`dist/`だけを公開します。Actionsタブから手動実行もできます。

Three.jsのMITライセンス表記は`public/THIRD_PARTY_LICENSES.txt`に含め、ビルド時に公開ファイルへコピーします。

## 開発

```sh
npm run format
npm run format:check
npm run check
npm run build
```

チェック本体は`scripts/check.ts`にあり、型チェック後に`esbuild`で一時ファイルへまとめて実行します。
